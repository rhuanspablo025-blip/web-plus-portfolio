# Web Plus — site e portfólio

Site institucional estático da Web Plus, com apresentação dos serviços, produtos, projetos e portfólios dos sócios Rhuan e Tiago.

## Páginas

- `index.html`: apresentação da empresa, serviços, destaques e equipe.
- `portfolio.html`: projetos e frentes de atuação da Web Plus.
- `rhuan.html`: biografia e portfólio de Rhuan.
- `tiago.html`: biografia e atuação comercial de Tiago.

## Desenvolvimento

Abra `index.html` no navegador ou sirva esta pasta com `python3 -m http.server 8000`. O site usa HTML, CSS e JavaScript, sem processo de build.
